# Fuwa representative game art

`fuwa-generated.png` was created with the built-in image generation tool, using the actual canonical side-standing reference at https://fuwa.dad/assets/ref/fuwa/fuwa-pose-stand-side.png (gallery: https://fuwa.dad/assets/#ref).

It is a new raster illustration, not a hand-coded SVG and not a copy of the reference pixels. Fuwa's long gray/beige coat, large ruff and plume tail, tufted ears, yellow-green eye and pink nose guided the image generation. Complete prompts are retained in `GENERATION-PROMPTS.txt`.

Original file: 1536 × 1024, RGBA. The game uses an in-memory texture frame x=51, y=96, width=1449, height=810 to remove transparent margins without changing the source image.

**Animation limitation:** this is one representative right-facing standing pose. Phaser adds small body motion, jump tilt, landing dust and collection effects; it is not a finished frame-by-frame running/jumping cycle. A cleanup variant was evaluated but not used because the original better preserved the plume tail.
