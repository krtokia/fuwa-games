# 후와 게임 — game.fuwa.dad

빌드 없는 정적 사이트. Cloudflare Pages 가 main 을 그대로 배포한다.

- `/` — 게이트웨이(게임 목록). 게임을 추가하면 `index.html` 의 `.games` 에 카드를 하나 더 넣는다.
- `/cat-outing/` — 고양이 나들이. 판 = 칸 수(3~7) × 난이도(쉬움~아주 어려움, `DIFFS` 표) × 판 번호(1~99999), 셋이 같으면 같은 판. 기록·별·고양이 빈도는 localStorage `cat-outing.v2`. 고양이 이름은 실제 이름이라 고정(그림 번호: 01 후와 · 04 슈리 · 02 나비 · 03 두부 · 07 봉봉 · 08 로로 · 05 꼬미 · 06 나무 순서. 기본 등장은 후와·슈리·나비 2배), 사람별로는 등장 빈도만 바꾼다. 고양이 그림은 `cat-outing/cats/<번호>-<칸수>.webp`(320px, 위를 보는 모습, L칸이면 세로 L배). 원본 512px PNG 는 GPT 가 up.fuwa.dad 로 올린 것.

새 게임은 폴더 하나(`/<이름>/index.html`)로 넣는다. 경로는 폴더 안 상대 경로로 쓸 것.

## 후와 달리기 v0.9 · 빠른 점프와 착지

`/cat-runner/`는 Phaser 3.90 기반 44초 러너다. 기본 속도는 360px/s, 선택 속도는 240px/s다. 일반 플레이어의 조작감을 먼저 다듬는다.

### 조작과 움직임

- 한 번 누르면 낮은 점프, 떼었다가 공중에서 다시 누르면 2단 점프다. 누르는 길이는 높이를 바꾸지 않는다. 입력 순간 속도를 바꾸며, 준비 동작 때문에 물리 반응을 늦추지 않는다. 세 번째 입력과 자동 반복은 받지 않는다.
- 첫 점프는 약 0.95초에서 0.663초로 짧아졌다. 빠르게 솟고 더 강한 중력으로 내려온다. 최고 높이는 90.25px에서 77.44px로 낮췄다. 보통의 2단 점프는 약 1.18–1.23초, 최고 높이 약 183–185px다.
- 2단 점프에 실제로 다른 모으기·차기 그림 두 장, 착지에 눌림·회복 그림 두 장을 쓴다. 각 짧은 동작은 약 0.14초다. 착지 동작 중 다시 누르면 즉시 새 점프로 넘어간다. 음향과 2단 점프 효과도 입력 순간 시작한다.
- 게임 세계의 최소 가로 폭은 720이다. 좁은 화면에서도 HUD·글자·점프 버튼 크기를 유지하며, 보이는 코끝 235px 기준 기본 속도에서 약 1.35초의 접근 구간을 확보한다. 바닥은 화면 높이의 약 82%에 둔다.

### 코스와 피격

- 12개 구간은 4, 7, 10, 14, 18, 20, 23, 27, 31, 33, 37, 40초에 시작한다. 낮은 상자, 긴 화분, 빈 바닥, 낙차, 올라가는 길, 높은 상자를 조합한다. 무작위 배치가 아니다.
- 짧아진 점프에 맞춰 낮은 상자 폭은 속도×0.12초, 긴 화분은 ×0.64초, 구멍은 ×0.70초로 다시 맞췄다. 33초의 높은 상자는 높이 105px, 폭은 속도×0.16초다. 두 속도에서 비슷한 체공 예산을 쓰도록 공간 길이를 바꾼다.
- 첫 점프 안내는 보통 0.50초 전, 높은 상자는 0.81초 전에 시작한다. 두 번째 안내는 첫 입력 후 긴 화분·구멍 0.18초, 높은 상자 0.14초다. 먼 거리의 경고는 “준비”, 실제 입력 시점은 “지금 톡”으로 구분한다.
- 바닥 높이 0, −54, +48과 실제 구멍을 유지한다. 정확한 정점·바닥 접촉·지형 경계 시점으로 나누어 계산한다. 높은 턱의 옆면을 통과하거나 구멍 위 공중에 착지하지 않는다.
- 긴 화분과 높은 상자는 단일 점프로 넘을 수 없다. 구멍은 걸어 나간 뒤 남은 공중 점프로 복구할 수 있는 여유를 허용하므로, 모든 구멍이 두 번의 실제 입력을 강제한다고 주장하지 않는다.
- 생선 10점, 별 50점, 연속 통과 20–40점이다. 보상 높이도 새 궤적에 맞췄으며 모든 별 7개를 모을 수 있다. 기록은 `fuwa-runner.v2`의 `score_v9_<mode>`로 이전 코스와 분리한다.
- 피격 시 0.85초 동안 후와가 정면을 보며 하악한다. 남은 시간, 거리, 장애물, 간식, 점프 물리와 무적 시간도 함께 멈춘다. 반응 중 입력은 저장하지 않는다. 일시정지는 남은 반응을 보존하며, 마지막 목숨이면 반응 뒤 결과로 넘어간다. 마지막 추락도 안전한 가장자리에서 표정을 보여 준다.
- 소리는 기본 꺼짐이다. 켜면 112BPM 합성 음악과 짧은 효과음이 나온다. 하악은 약 0.32초의 합성 소리이며 실제 고양이 녹음이 아니다. 피격 동안 음악도 쉬었다 이어진다.
- 기존 `cat-outing/` 코드·그림·기록은 바꾸지 않는다. 탭 이탈과 화면 크기 변경은 일시정지한다.

### 배치에 쓰는 계산

첫 점프 속도 440, 상승 중력 1250, 하강 중력 1600이다. 상승 구간은 `y(t)=440t−625t²`이며, 정점까지 0.352초, 최고 높이 77.44px다. 정점 뒤에는 하강 중력으로 계산해 같은 바닥까지 총 약 0.66313초가 걸린다. 2단 입력은 현재 속도에 더하지 않고 위쪽 속도 520으로 교체한다. 가능한 최고 높이는 185.60px다.

긴 화분의 실효 충돌 높이 22px 위에 머무는 단일 점프 시간은 약 0.561초다. 화분 폭과 몸통·충돌 여유를 포함한 구간은 기본 속도 약 0.673초, 느린 속도 0.690초여서 한 번의 점프로 부족하다. 높은 상자는 실효 높이 95px가 첫 점프 최고 77.44px보다 높다.

안내 후 80–250ms 반응과 렌더링 지연을 포함한 보수적 계산에서도 높은 상자 약 7.77px, 긴 화분 끝 약 10.50px, 구멍 끝 약 22.60px의 통과 여유가 있다. 다음 안내 전 착지·회복 시간도 별도로 검사하며 가장 짧은 구간은 약 0.945초다.

### 그림의 출처와 한계

후와 그림은 실제 참고 그림 https://fuwa.dad/assets/ref/fuwa/fuwa-pose-stand-side.png 와 https://fuwa.dad/assets/ref/fuwa/fuwa-front.png 를 보고 이미지 생성 도구로 만들었다.

- `fuwa-generated.png`: 시작·대기 포즈.
- `fuwa-motion-v1.png`: 실제 다리와 몸 자세가 다른 달리기 6프레임, 상승·하강 2포즈.
- `fuwa-jump-land-v1.png`: 2단 점프 모으기·차기, 착지 눌림·회복의 서로 다른 4포즈.
- `fuwa-hiss-front-v1.png`: 플레이어를 보는 정면 하악 포즈 한 장. 몸을 돌리는 연속 회전 애니메이션은 아니다.
- `moonlit-alley-v1.png`: 생성한 한옥 골목 배경. 완벽한 반복 타일이 아니므로 제한된 범위에서 천천히 이동한다.

새 동작은 실제 그림 교체와 작은 자세 보정이며, 완성된 리깅 애니메이션은 아니다. 프레임마다 털·체형·정합에 작은 차이가 있고 일부 다리가 긴 털과 섞인다. 차기 그림의 발이 가상 기준점 아래로 뻗는 부분은 바닥 가까이에서 그림 위치만 보정한다. 충돌 판정은 그림의 외곽선이나 프레임에 따라 바꾸지 않는다. 상세 출처와 프롬프트는 `cat-runner/assets/` 문서에 있다.

### 실행과 검사

Pages의 빌드는 필요 없다. Phaser 런타임을 MIT 라이선스와 함께 저장소에 포함하여 외부 CDN 없이 정적으로 실행한다.

```sh
python3 -m http.server 8000
# http://localhost:8000/cat-runner/
node --test cat-runner/tests/*.test.mjs
node --check cat-runner/game.mjs
```

`python3 cat-runner/scripts/build-standalone.py /tmp/fuwa-runner.html`로 오프라인 검토용 단일 HTML을 만들 수 있다. 운영 배포에는 이 단계가 필요 없다.

자동 검사는 32,508개의 개별 위험 반응 조합과 432개의 전체 코스를 포함한다. 두 속도, 네 월드 폭, 30/60/120Hz, 첫·두 번째 안내에 대한 반응 지연, 모든 별, 지형 경계, 마지막 순간의 점프, 피격 정지, 일시정지, 재시작을 검사한다. 실제 장면 갱신 함수를 쓰는 렌더링 대역 검사와 터치 형태의 Pointer Event 검사도 있다. 이는 실제 휴대폰이나 브라우저 모바일 에뮬레이션을 대신하지 않는다. 기기 터치·화면 회전·소리 청취는 별도 검토가 필요하다.

기능 브랜치를 푸시하면 Cloudflare Pages 미리보기에서 검토한다. main 병합은 별도이며 병합 시 운영 사이트에 새 경로와 목록 카드가 배포된다.
