# 후와 게임 — game.fuwa.dad

빌드 없는 정적 사이트. Cloudflare Pages 가 main 을 그대로 배포한다.

- `/` — 게이트웨이(게임 목록). 게임을 추가하면 `index.html` 의 `.games` 에 카드를 하나 더 넣는다.
- `/cat-outing/` — 고양이 나들이. 판 = 칸 수(3~7) × 난이도(쉬움~아주 어려움, `DIFFS` 표) × 판 번호(1~99999), 셋이 같으면 같은 판. 기록·별·고양이 빈도는 localStorage `cat-outing.v2`. 고양이 이름은 실제 이름이라 고정(그림 번호: 01 후와 · 04 슈리 · 02 나비 · 03 두부 · 07 봉봉 · 08 로로 · 05 꼬미 · 06 나무 순서. 기본 등장은 후와·슈리·나비 2배), 사람별로는 등장 빈도만 바꾼다. 고양이 그림은 `cat-outing/cats/<번호>-<칸수>.webp`(320px, 위를 보는 모습, L칸이면 세로 L배). 원본 512px PNG 는 GPT 가 up.fuwa.dad 로 올린 것.

새 게임은 폴더 하나(`/<이름>/index.html`)로 넣는다. 경로는 폴더 안 상대 경로로 쓸 것.

## 후와 달리기 v0.7 · 높은 상자와 후와의 하악 반응

`/cat-runner/`는 Phaser 3.90 기반44초 러너다. 기본360px/s, 선택240px/s이며 일반 플레이어의 조작감을 우선한다.

- 게임 세계의 최소 가로 폭을440에서720으로 넓혔다. 좁은 화면의 후와·장애물은 이전보다 약39% 작게 보이고, HUD·글자·점프 버튼 크기는 유지한다. 보이는 코끝235px를 기준으로 `(720−235)/360 ≈ 1.35초`의 접근 구간을 확보한다. 화면 비율에 따라 세로 월드 높이와 카메라 위치를 계산해 바닥을 화면 높이82%에 둔다.
- 한 번 누르면 낮은 점프, 떼었다가 공중에서 다시 누르면 두 번째 점프다. 누르는 시간은 높이를 바꾸지 않는다. 긴 구간은 첫 점프 후 약0.4~0.6초 뒤 두 번째 입력을 받도록 안내한다.
- 코스는 낮은 상자 → 긴 화분 → 빈 바닥 → 낮은 길 → 높은 길 → 높은 상자로 익히고 조합한다. 33초에는 높이125px의3단 상자를 두어 2단 점프를 확실히 요구한다. 12개 구간은4,7,10,14,18,20,23,27,31,33,37,40초에 시작한다. 긴 화분·구멍 길이는 속도×0.95초이므로 두 속도에서 비슷한 체공 예산을 쓴다.
- 바닥 높이는0, −54, +48이고 구멍에는 지면이 없다. 아래로 지나가며 실제 지면을 가로지를 때만 착지한다. 높은 턱을 통과하면 벽 충돌로 처리한다. 추락·벽 충돌 후에는 기운1개와 짧은 구조 표시를 사용해 안전한 가장자리로 돌아온다. 구멍 위로 보이지 않는 일반 바닥을 깔지 않는다.
- 긴 화분은 한 번의 점프로 넘을 수 없다. 구멍에서는 이미 걸어 나간 뒤 남은 공중 점프 한 번으로 가까스로 복구할 여유를 허용하므로, 모든 구멍이 두 번의 실제 입력을 강제한다고 주장하지 않는다.
- 생선10점, 별50점, 연속 통과20~40점. 긴 구간의 보상은 길이15%·50%·75%에 놓고 가운데 별은 바닥보다170px 높다. 낙차 뒤 생선과 쉬는 구간 간식도 실제 바닥 높이를 따른다.
- 부딪히면 별도 생성 하악 포즈로0.55초 바뀌고 짧게 뒤로 움찔하며 “하악!”을 표시한다. 한 장의 표정 포즈와 절차적 반동이지 새로운 여러 프레임 얼굴 애니메이션은 아니다. 소리를 켰을 때0.32초의 부드러운 합성 하악 소리를 낸다. 실제 고양이 녹음이 아니다. 마지막 충돌도 반응을 보여준 뒤 결과를 열며, 음악은 즉시 멈춘다.
- 실제6프레임 달리기와 상승·하강 포즈, 생성 골목 배경, 수집·착지·피격·구조·완주 연출, 선택112BPM 합성 음악을 유지한다. 탭 이탈·화면 크기 변경은 일시정지한다.
- 기존 `cat-outing/` 코드·그림·기록은 바꾸지 않는다. 저장 키는 `fuwa-runner.v2`, 이번 점수 기록은 `score_v7_<mode>`로 이전 코스와 분리한다.

### 배치에 쓰는 계산

중력800, 점프 초기 속도380일 때 `y(t)=380t−400t²`, 최고 높이90.25px, 같은 높이까지 체공 시간0.95초다. 높이h 이상을 유지하는 시간은 `2√(380²−1600h)/800`이다.

긴 화분의 실효 충돌 높이22px 위에 머무는 단일 점프 시간은 약0.826초다. 화분 폭과 몸통 폭·여유를 포함한 충돌 구간은 기본 속도 약0.983초, 느린 속도1.000초여서 단일 점프로는 부족하다. 두 번째 입력으로 상승 속도를 다시 주면 통과할 수 있다. 다음 위험 전 착지 여유도 별도로 검사한다.

높은 상자는 실효 충돌 높이115px로 단일 점프 최고90.25px보다 높다. 폭은 속도×0.25초(90px/60px)이고, 첫 점프 안내를 도착1.0초 전에 시작하고, 첫 입력0.30초 뒤 두 번째 입력을 안내한다. 31초 낙차에서 착지할 시간을 확보하고, 37초 구멍 전에는 충분한 착지·회복 구간을 둔다.

무작위로 뽑은 장애물 사이 간격이 아니라, 위 계산과 물리 시뮬레이션을 모두 통과한 정해진 구간이다. 첫 입력은 안내 후80~250ms, 두 번째는 첫 입력400~600ms 뒤라는 범위에서도 두 속도로 완주한다.

### 이미지의 출처와 현재 한계

후와 그림은 https://fuwa.dad/assets/ref/fuwa/fuwa-pose-stand-side.png 를 직접 보고 이미지 생성 도구로 만들었다. `fuwa-generated.png`는 시작·대기 포즈, `fuwa-motion-v1.png`는 다리와 몸 자세가 실제로 달라지는6개 달리기 프레임과2개 공중 포즈다. 손으로 그린 SVG 고양이나 한 장을 흔드는 방식이 아니다.

`fuwa-hiss-v1.png`는 같은 후와 참고 그림과 달리기 아틀라스를 보고 만든 단일 하악 반응 포즈다. 작은 화면에서 표정을 읽을 수 있도록 열린 입, 뒤로 젖힌 귀, 부푼 등과 꼬리를 사용한다.

`moonlit-alley-v1.png`는 같은 화풍으로 생성한 한옥 골목 배경이다. 가장자리가 완전히 이어지지 않으므로 반복 타일 대신 제한된 범위의 느린 이동으로 사용한다. 상세 출처와 프롬프트는 `cat-runner/assets/`의 문서에 있다.

프레임별 털·체형과 위치에 미세한 차이가 있고 일부 다리가 긴 털에 섞인다. 현재는 첫 게임 구간을 검증하는 생성 애니메이션이며, 손으로 정합한 최종 애니메이션은 아니다. 실제 휴대폰 터치와 기기별 음향·성능은 추가 검토가 필요하다.

### 실행과 검사

Pages의 빌드는 여전히 필요 없다. Phaser 런타임을 MIT 라이선스와 함께 저장소에 포함하여 외부 CDN 없이 정적으로 실행한다.

```sh
python3 -m http.server 8000
# http://localhost:8000/cat-runner/
node --test cat-runner/tests/*.test.mjs
node --check cat-runner/game.mjs
```

원하면 `python3 cat-runner/scripts/build-standalone.py /tmp/fuwa-runner.html`로 오프라인 검토용 단일 HTML을 만들 수 있다. 운영 배포에는 이 단계가 필요 없다.

기능 브랜치를 푸시하면 Cloudflare Pages 미리보기에서 검토한다. main 병합은 별도이며 병합 시 운영 사이트에 새 경로와 목록 카드가 배포된다.

자동 검사는216가지 코스 조합(두 속도·네 월드 폭·30/60/120Hz·세 반응 지연·세 두 번째 입력 간격), 각 위험을 일부러 놓친 뒤 복구, 실제 착지·턱 충돌·입력·음향·월드 시야를 다룬다. 높은 상자는 단일 입력742개 타이밍·2단 입력756조합·안내 후80~250ms 반응4,536조합으로 두 속도에서 검사한다. 실제 휴대폰 터치·화면 회전·기기별 음향은 별도 검토가 필요하다.
